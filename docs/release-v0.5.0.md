# v0.5.0 整体验收与发布准备

QuantItera：开放式自主迭代量化研究引擎。Discover. Reason. Validate. Evolve.

本版承接 V6/P1、统一工作空间、真实研究反馈和两份成绩报告，整理为可从空白使用的开源源码项目。MIT 保留；不含私人模型、策略、账户、真实研究档案或私人 Git 历史。

## 功能清单

| 范围 | 本版可用行为 |
| --- | --- |
| 初始化 | 空白工作空间、ChatGPT 研究入口、独立数据/请求/导出、GitHub 日程模板 |
| 研究对象与数据 | 显式 asset；自己的行情入口，身份、币种、口径、日历及可获知时间检查 |
| V6 机制 | 原始证据、事前预期、修订与冲突、期限、支持/反证、竞争解释、证伪和下一观察 |
| 归档与验证 | 请求回执、不可覆盖判断、review_at/review_spec、客观成熟条件、复杂/政策待评价 |
| 学习与下一轮 | 支持/反驳、错误、缺口、仍有效机制、新假设，discuss 自动读取并传给模型 |
| 模型 | 可选本地 provider、独立资产模型、全资产组合模型、来源和反馈一致性 |
| 成绩 | 研究数量/期限/版本/机制/因子进展；账户资金流、费用、汇率、净收益和风险口径；缺失不补造 |
| 展示与维护 | 循环图、模块图、十步指南、两个可运行合成示例、可阅读报告、贡献与版本说明 |

2026-10-20 本地公开测试 **83 项通过**。相比 v0.4.0，新增完整新用户教程、复制出的模型/未登记资产隔离，以及独立 performance 更新机制的回归测试。

研究教程使用真实 CLI、inbox/outbox 和同一导出器：

- 先以空白目录运行，再添加两个合成研究对象、模型和带时间的行情。
- 原预期 3.00、后发布事件 2.75，比较为 -0.25 个百分点；机制同时保留支持、反证和竞争解释，不声明因果已识别。
- 两条未来市场条件分别 supported/refuted；复杂判断先 awaiting_evaluation，再通过示例人工复盘完成，但不自动整体打分。
- 下一轮判断和模型取得历史反驳、错误与新假设；所有资产交给组合接口，模型版本不变。
- 最终 4 项研究判断、3 项已完成复盘（1 支持、1 反驳、1 未整体打分），1 项后续待到期；重复刷新新增复盘为 0，原判断不改写。
- 教程没有账户时，真实成绩明确缺数据；分享默认关闭。

账户示例继续复用 v0.4.0：期初 1000，入金 500、出金 200，期末 1395，其中费用 5 已包含于估值；净收益额 95、TWR 9.5%，不会重复扣费或把市值差当收益。不足一年不年化；短样本风险统计仅展示算法，不代表长期能力。

CI 在标准 Ubuntu 验证公开测试、构建 wheel、全新环境安装、空白 Git 初始化/克隆及模板保存路径，再将 examples 复制到源码以外运行教程、复制出的模型、重复刷新和成绩示例。它不访问私人仓库、账户、模型或密钥。以对应 PR/commit 的 [CI 结果](https://github.com/wysking/quantitera/actions/workflows/ci.yml) 为准。

本轮 Windows / Python 3.12 下使用 v0.5.0 源码，**17 项私人兼容测试通过**。未修改原私人项目源码、账户或策略；测试写入临时工作空间，原底稿与冻结模型指纹前后相同。

## 安装与发布维护

源码版本和 Git tag 均为 v0.5.0；Python 包版本为 0.5.0。模板安装同一 tag，不跟随浮动分支。未向 PyPI 发布同名包。

维护者先核对整体验收 PR、CI、MIT、合成例子及打包清单，再合并默认分支。发布版本固定到验收提交，不重写已用 tag；GitHub Release 可先保存草稿，发布前核对目标 tag、说明及包摘要。已有工作空间只升级安装版本/工作流 pin，不重建数据目录。

构建（开发环境另装标准 Python build 工具即可，不是运行时依赖）：

```sh
python -m build --sdist --wheel
```

wheel 包含通用引擎、空白模板与 MIT；sdist 另含公开文档、测试和合成示例，不包含 runtime 或任何个人工作空间。

## 仍待改进及明确边界

- 日历目前覆盖 2021—2026，后续年份和更多标的需官方来源及边界测试，未知身份不猜测。
- 行情导入依赖用户入口，没有通用下载、实时数据服务或市场数据再分发。
- 最新信息搜索、竞争解释与复杂因果研究由研究者/ChatGPT 完成，没有后台收费大模型或自动因果识别。
- 旧文字复盘缺整体打分时保持未打分；没有可比资产/期限/基准、独立样本和不确定性设计时，不宣称方法已改善。
- 真实收益依赖完整资金流、费用、净值、汇率和基准；缺数据的账户不能生成真实收益能力结论，交易关联须明确记录。
- 模型反馈不是自动调权/训练；因子研究复用私人已有流程，不附送默认私人策略或因子库。
- GitHub 日程需在自己的私有默认分支部署，受权限、额度和平台调度影响；公开 CI 的模板验收不等于替用户部署或保证准时触发。
- 分享摘要默认关闭，选择后也只生成本地文件；没有自动公开私人报告的发布功能。

这些边界在 README、工作空间入口和示例中保持一致，功能描述以实现为准。
